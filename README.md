# One Word From Grandma

Entry for the [make.fun competition "One Word From Grandma"](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

`main.py` scores ten fresh one-word candidates a grandma would text about
AI — on originality, humour, grandma theme, the exact one-word format, and
natural English — and writes the winner to `/output/entry.txt`:

> computor

The computer with its "e" dropped, exactly how a baffled grandma texts
about the machine that thinks: warm, funny, tied to AI, and fresh against
a field of 2,486 entries full of robots and doohickeys.

Run locally:

```sh
python3 main.py
cat /output/entry.txt
```

Python 3, standard library only, deterministic — no network, no randomness, no clock.
